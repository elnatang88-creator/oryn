# העלאת ORYN לקישור אונליין (Vercel) — אפשר לבצע מהטלפון

המטרה: קישור שנפתח מכל טלפון, כדי לסרוק QR מטלפון אחד ולפתוח אותו בטלפון אחר.
כל החשבונות חייבים להיות **בבעלות החברה** (אימייל של החברה, אימות דו־שלבי).

> נבדק לפני כתיבת המסמך: האפליקציה עוברת את כל הבדיקות גם על PostgreSQL אמיתי במצב production. גם הפעלה של 8 שרתים במקביל עוברת: הטבלאות נוצרות פעם אחת ונתוני הדמו נכנסים פעם אחת.

## 1. פרויקט ב-Vercel
1. נכנסים ל-vercel.com עם חשבון החברה.
2. אם הריפו `oryn` כבר מחובר לפרויקט — ממשיכים. אחרת: **Add New → Project** ובוחרים את `elnatang88-creator/oryn`.
3. כל ענף מקבל כתובת תצוגה (Preview) משלו, כולל `oryn-v1`. את `main` לא צריך לשנות.

## 2. מסד נתונים
1. בפרויקט: **Storage → Create Database → Postgres (Neon)**.
2. בוחרים אזור קרוב (למשל Frankfurt) ומחברים לפרויקט.
3. זה מוסיף את `DATABASE_URL` לפרויקט אוטומטית. הטבלאות נוצרות לבד בהפעלה הראשונה.

## 3. משתני סביבה
ב-**Settings → Environment Variables** מוסיפים את המשתנים הבאים, מסומנים ל-**Preview**:

| שם | ערך |
|---|---|
| `ORYN_SECRET` | מחרוזת אקראית של 40 תווים לפחות. אפשר לייצר באייפון (הגדרות → סיסמאות → יצירת סיסמה). **לא לשלוח אותה בצ'אט או במייל.** |
| `ORYN_SEED_DEMO` | `true` — יוצר את חשבון הדמו ואת הדוכן `/q/harbordemo`. **רק לתצוגה, לא ל-Production.** |
| `ORYN_DEMO_PASSWORD` | סיסמה שתבחרו לחשבון `demo@oryn.local` |
| `ORYN_JOBS_INLINE` | `true` — מכין קובצי ייצוא נתונים מיד |
| `CRON_SECRET` | מחרוזת אקראית (משמשת את המשימה היומית ב-`vercel.json`) |

את `NEXT_PUBLIC_APP_URL` לא מגדירים בשלב התצוגה — הכתובת נלקחת אוטומטית מהדומיין של הבקשה.

## 4. לאפשר לאנשים בלי חשבון Vercel לפתוח את הקישור
ב-Vercel, כתובות Preview מוגנות בכניסה ל-Vercel כברירת מחדל, ואז הנמען יתבקש להתחבר ל-Vercel.
**Settings → Deployment Protection** → לכבות את **Vercel Authentication** לכתובות Preview.
(לחלופין: **Protection Bypass / Shareable Link** — אבל אז כל נמען צריך את הקישור המיוחד.)

## 5. פריסה
**Deployments** → הפריסה האחרונה של הענף `oryn-v1` → **⋯ → Redeploy**. פריסה מחדש נדרשת כדי שהמשתנים ייכנסו לתוקף.
כשהסטטוס Ready, פותחים את הכתובת (בסגנון `https://oryn-git-oryn-v1-….vercel.app`):

- **כניסה:** `/signin` עם `demo@oryn.local` והסיסמה מסעיף 3
- **דף נמען לדמו:** `/q/harbordemo`
- **בדיקת תקינות:** `/api/health` צריך להחזיר `{"ok":true}`

## 6. בדיקת הפריסה
מהמחשב, בתיקיית הפרויקט:
```bash
npm run verify:http https://<הכתובת-שקיבלתם>
```
התוצאה צריכה להיות `0 failing`. אם `/api/health` מחזיר 401, ההגנה מסעיף 4 עדיין פעילה.
לבדיקת משתני הסביבה ומסד הנתונים (בלי להציג ערכים): `vercel env pull` ואז `npm run verify:env`.

## 7. מה עוד חשוב לדעת
- **משימות רקע:** כתובת Preview מקבלת משימה יומית אחת בלבד. מחיקת חשבון מתבצעת ביום שאחרי תום 7 ימי ההמתנה.
- **Production:** לדומיין האמיתי ולמשתמשים אמיתיים — `ORYN_SEED_DEMO` כבוי, `NEXT_PUBLIC_APP_URL` מוגדר לדומיין, ועוברים קודם על רשימת "לפני משתמשים אמיתיים" ב-`MVP_QA_REPORT.md`.
- **תקלה:** אם משהו לא עולה — שלחו את הכתובת ואת השגיאה מ-**Deployments → Logs**, ואבדוק.

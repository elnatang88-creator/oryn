# MedFlow AI Planning Docs

This folder holds planning artifacts for **MedFlow AI**, a proposed healthcare
revenue-cycle-recovery product for U.S. medical billing / RCM companies.

**Note on scope:** this repository (`oryn`) is a digital business-card /
lead-capture SaaS application and is unrelated to MedFlow AI's product
domain (healthcare claims, denials, and payer recovery). These documents were
added here because the task that generated them targeted this repo directly.
If MedFlow AI is a separate product effort, these files should be moved to
their own repository rather than developed alongside the `oryn` codebase.

## Contents

- [`master-prompt.md`](./master-prompt.md) — the full operating brief (role,
  workstreams, canonical 10-step system workflow, AI guardrails, source
  rules, security/compliance requirements, business model framework, and
  team/ownership rules) that governs how MedFlow AI product, business, and
  team artifacts should be produced.
- [`business-model.md`](./business-model.md) — the first deliverable called
  for by the master prompt's "START NOW" instruction: a one-page
  monetization model (Workstream: Business only — no product architecture,
  no team/equity content).

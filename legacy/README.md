# Legacy: business-card prototype (v0)

The code in `business-card-v0/` is the earlier ORYN prototype (Next.js + Supabase digital business card with a gold/obsidian theme). It is preserved here unchanged for reference and is **not** compiled, linted or deployed (`tsconfig.json` excludes `legacy/`).

It was replaced because the product direction changed from "a digital business card" to the Identity Capsule model, and because parts of it conflict with ORYN's privacy principles (it stored viewer IP addresses and showed simulated "viewer" data). Its git history remains intact (last commit before the move: `6ae925a`).
